# 🛍️ بوت متجر MZ للخدمات الرقمية (MZ Store Bot)

بوت تيلجرام لمتجر **MZ** للخدمات والمنتجات الرقمية، التابع لشركة **ليمونة تيك (Laymouna Tech)** ومنصة **ماركت هب (Market Hub)**.

- **المعرف الرسمي للبوت:** [@MZ_StoreHub_Bot](https://t.me/MZ_StoreHub_Bot)

---

## 🌟 الأقسام والتطبيقات المتوفرة:
1. 🎬 **اشتراكات الترفيه:** Netflix 4K, Shahid VIP, YouTube Premium, Spotify, IPTV 4K.
2. 🤖 **الذكاء الاصطناعي والتصميم:** ChatGPT Plus, Canva Pro, CapCut Pro, Duolingo Super.
3. 🎮 **شحن الألعاب والبطاقات:** شدات ببجي (PUBG UC), جواهر فري فاير, بطاقات PlayStation, Steam.
4. 💻 **البرامج الأصلية:** مفاتيح تفعيل Windows 10/11 Pro, وحزم Microsoft Office 365 Pro.
5. ✈️ **تيلجرام والسوشيال ميديا:** اشتراك Telegram Premium, خدمات المتابعين والتفاعل.
6. 🍋 **حلول ليمونة تيك وماركت هب:** تأسيس المتاجر الإلكترونية وبرمجة البوتات والحلول التقنية.

---

## 🚀 الأوامر المتاحة:
- `/start` - القائمة الرئيسية وتصفح الكتالوج والأقسام.
- `/catalog` - استعراض الخدمات والتطبيقات المتاحة.
- `/track <كود_الطلب>` - الاستعلام عن حالة الطلب.
- `/setgroup` - ربط مجموعة التيلجرام الخاصة بفريق العمل لتلقي إشعارات الطلبات الفورية.
- `/stats` - إحصائيات الطلبات والمبيعات.
